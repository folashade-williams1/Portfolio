A Cafeteria App

Full description

The PAU Cafeteria App is a desktop application I built as a class assignment, using JavaFX for the interface and PostgreSQL for the database. It lets customers log in, browse the menu, add items to a cart and place an order, while managers have a separate dashboard to oversee the cafeteria. The app follows an MVC (Model-View-Controller) structure, separating the interface, the data and the logic that connects them.

The problem I solved

A cafeteria needs a way to take orders and manage the menu without relying on paper or manual tracking, while also keeping customer and staff access separate. The app addresses this by giving customers a self-service way to order food, and giving managers a dashboard to oversee operations, with each role seeing only the screens meant for them.

Features

  • Sign up and log in, with passwords stored securely using BCrypt hashing
  • Separate roles for Manager and Customer, each seeing different screens
  • Shopping cart for customers
  • Order placement saved to a PostgreSQL database
  • Manager dashboard for overseeing cafeteria operations:adding or deleting items, editing prices and descriptions

What I learned

This was my first substantial Java and JavaFX project, and it was where I properly learned how MVC architecture separates concerns in a real application, rather than just as a diagram in a lecture. Working with PostgreSQL also taught me how a desktop app connects to and manages a live database, and implementing BCrypt gave me a practical look at why passwords should never be stored as plain text. If I built it again, I'd plan the database tables more carefully before writing the interface.
